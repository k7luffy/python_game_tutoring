Python Maze Adventure: The Coin Mission

Teacher-only reference for the Create mission, the four maze levels and the boss. Students start from an empty editor; share hints, not this page.

Level economy at a glance

Each move costs 1 coin. Gold coin +10, treasure chest +20. A level passes when the base is reached with at least 0 coins. The final base tops the player up to 50 coins for the boss, and the boss practice run starts with the same 50. Every boss move also costs 1 coin.

Create Your Explorer

Ask the player for a name with input(), store it in player_name, then print a welcome that includes the name.

player_name = input("What is your name? ")
print("Welcome,", player_name)

Sample run: the player types Nova → player_name = "Nova" and the console shows the welcome. weapon_power is fixed at 5 by the game.

Boss: Super Attack

The boss starts at the top-left start tile with 50 coins (checkpoint top-up) or 50 coins in a practice run. Students walk to the cyan attack pad two tiles above the boss, then write a function that checks coins >= 30 and fires only inside the if branch. The boss tile itself is blocked, every move costs 1 coin, and the shortest walk to the pad is 20 steps - arriving with exactly 30 coins.

Full program

def super_attack():
    if coins >= 30:
        print("Super Attack Activated!")
        fire_super_attack()
    else:
        print("Not enough coins!")

super_attack()

The route above is the reference walk; the second block is the full program. The game refuses fire_super_attack() unless the robot stands on the pad and the call sits inside an if coins >= 30: check. If the function is never called, the fire line is missing, or the guard is absent, the boss survives and the game shows a hint on the notice card.
